# Mfarmani
This repository contains my personal webpage


## Portfolio design

All pages use `assets/css/portfolio.css` and `assets/js/portfolio.js`.
The homepage highlights selected research, software, and contact information.
Research pages retain their figures and section links. Background videos are
no longer embedded; archived video files and older styles remain in the
repository but are not loaded by the pages.

Preview locally from this directory:

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000. The site is static and requires no build step.
