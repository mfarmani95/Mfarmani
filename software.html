Open Source Software Packages

These tools are developed to support hydrologic, climate, and data-intensive research. Together they reflect how I work across environmental science, computational modeling, and scientific machine learning.

Coffee suitability & forest-loss analysis

YAML-driven geospatial workflow combining NDVI, rainfall, soil moisture, and forest-loss layers. Harmonizes inputs to a common monthly grid and applies configurable suitability thresholds. Includes a clearly labeled synthetic demo.

Python · Remote sensing · Raster processing

Remote data jobs: SQL analysis

PostgreSQL analysis of job-posting data to compare skill demand and reported salaries, with reproducible Python visualizations. Results describe the source dataset rather than the current job market.

SQL · PostgreSQL · Data visualization

smm-toolkit

A Python package to compute long-term and short-term Soil Moisture Memory (SMM) for hydrological and climate research.

  • Language: Python
  • Initial Release: 2025

bfi-toolkit

A toolkit for Baseflow Index (BFI) analysis and hydrological decomposition of streamflow time series.

  • Language: Python
  • Initial Release: 2025
PyPI GitHub

RiverGraphNet

A graph-based routing framework for transporting physically generated runoff through directed river networks using topology-aware machine learning.

  • Language: Python
  • Focus: River routing, graph neural networks, hydrologic prediction

Streamflow Prediction Dashboard

An interactive application and modeling workflow for comparing LSTM and Transformer approaches to streamflow prediction in CAMELS-style basins.

  • Language: Python
  • Focus: Sequence models, experiment workflows, interactive dashboard
